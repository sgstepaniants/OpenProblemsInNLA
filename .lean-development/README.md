# Unverified Lean development drafts

This branch hosts remote Linux elaboration checks for proposed statements.
The Challenge files intentionally contain placeholders. A successful development
run proves no mathematical theorem and is never a completed verification.
Canonical problem statuses and the final verification harness are unchanged.
Two independent statement approvals and actual successful elaboration are needed
before each statement boundary is frozen and proof implementation begins.

Final solution verification uses the repository's separately reviewed Linux
Comparator/default-kernel harness with source-bound evidence and rejection controls,
followed by independent mathematical reviews and one PR per complete problem.

Formalization author: George Stepaniants, Department of Computing and Mathematical
Sciences, California Institute of Technology, Pasadena, California, USA.
Substantial AI assistance; mathematical sources retain their original attribution.
